# PedroDevTools

Локальные инструменты для видео, фото, музыки и картинок: апскейл нейросетью
и 15 инструментов на ffmpeg, 17 вкладок в 4 группах. Всё считается на своей
машине, файлы никуда не уходят.

MIT, автор MrBoBo2010 (PedroDev).

## Возможности

| Группа | Вкладки |
|---|---|
| Видео | апскейл нейросетью · размер · компрессор · скорость · нарезка · поворот · видео→аудио · видео→GIF · видео+аудио |
| Фото | апскейл нейросетью · размер · компрессор |
| Аудио | компрессор · громкость (EBU R128) · нарезка |
| Файлы | конвертер · метаданные |

- **Интерфейс**: простой и расширенный режимы, тёмная и светлая темы, группы
  вкладок со счётчиками, превью исходника и результата в браузере.
- **Размер**: одна вкладка с галочкой «Сохранять пропорции». Снята — ровно
  `ширина × высота`; 0 в стороне берёт размер исходника.
- **Нарезка**: края выделения тянутся мышкой, секунды можно вписать и вручную.
- **Апскейл фото**: те же движки и модели, что и у видео, одним кадром.
- **Пресеты**: 5 встроенных, свои сохраняются в `presets/`.

## Установка

Нужен Python 3.11+, `ffmpeg` с `ffprobe` в PATH и интернет один раз.

**1. ffmpeg** — <https://ffmpeg.org/download.html>, проверить: `ffmpeg -version`

**2. Движки нейросетей** (100 МБ, в репозиторий не входят):

```
powershell -ExecutionPolicy Bypass -File install-engines.ps1
```

| Движок | Куда | Релиз |
|---|---|---|
| Real-ESRGAN (Vulkan) | `bin\realesrgan\` | xinntao/Real-ESRGAN-ncnn-vulkan v0.2.0 |
| RealSR (CPU) | `bin\realsr\realsr-ncnn-vulkan-20220728-windows\` | nihui/realsr-ncnn-vulkan 20220728 |
| SRMD (Vulkan) | `bin\srmd\srmd-ncnn-vulkan-20220728-windows\` | nihui/srmd-ncnn-vulkan 20220728 |

Скрипт пропускает уже скачанные. **Веса моделей** качать не нужно: приложение
тянет их с HuggingFace при первом апскейле.

**3. Запуск** — двойной клик по `run.bat`, сервер на <http://127.0.0.1:8756>.

Вручную:

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python server\main.py
```

## Движки и модели

| | Движок | Масштабы | Скорость |
|---|---|---|---|
| GPU | `realesrgan-ncnn-vulkan` | ×2, ×3, ×4 | быстро |
| GPU | `srmd-ncnn-vulkan` | ×2, ×3, ×4 | в ~2.5 раза быстрее Real-ESRGAN |
| CPU | `realsr-ncnn-vulkan` | только ×4 | в десятки раз медленнее |

Модели: Real-ESRGAN — `realesr-general-x4v3` (дефолт), `AnimeSharp`,
`realesrgan-x4plus`, `realesrgan-x4plus-anime`, `realesr-animevideov3` ×2/×3/×4;
SRMD — `srmd-x2/x3/x4` и `srmdnf-x2/x3/x4` с денойзом; CPU — `DF2K` и
`DF2K_JPEG`. Скачиваются по требованию в `bin/`.

## Как работает

Видео идёт **чанками**: ffmpeg распаковывает кадры в PNG → движок увеличивает
каждый кадр → ffmpeg кодирует чанк → чанки склеиваются concat, аудио берётся
из исходника. Кадры чанка удаляются сразу после кодирования, поэтому расход
диска не растёт с длиной ролика; при нехватке места чанк мельчает сам.
Прогресс по кадрам, есть ETA и отмена.

Точный размер никогда не достаётся «грязным» способом: ключ `-s` движка всегда
равен родному масштабу модели, а разница добирается ресайзом Lanczos. Причина
конкретная: `-s 2` на ×4-модели даёт верный размер кадра с убитым цветом
(выживает только красный канал).

## Ограничения

- CPU-режим медленный: 640×360 ×4 — около 50 с на кадр, минута 1080p — часы.
- MKV и AVI браузер не играет, для них в интерфейсе только скачивание.
- Апскейл добавляет разрешение, а не детализацию: результат сразу кодируется
  с CRF, выше исходного качества не получится.
- Модели масштабируют целыми кратными, произвольные цели — через ресайз.
- `realesr-general-wdn-x4v3` в ncnn нет: только `.pth` под PyTorch.

## Проверки

Тесты в `tmp/`, гоняются против живого сервера на 127.0.0.1:8756.

```
python tmp\mediatest.py     # 15 операций, фикстуры создаёт сам (19 PASS)

python tmp\imgup_e2e.py     # апскейл фото на настоящем движке
python tmp\api_check.py     # вкладки, схемы операций
python tmp\live_check.py    # живой сервер (11 PASS)

cd tmp && npm install       # jsdom-тесты
node groups.js              # темы, группы, превью (40 PASS)
node tools.js               # режимы, цели, инструмент (22 PASS)
node btn.js                 # запуск и докачка модели (32 PASS)
```

`tmp/scan_mojibake.py` проверяет, что русский текст в исходниках не побит
перекодировкой.

## Структура

```
server/   main.py ffmpeg.py upscale.py imgup.py media.py models.py
          devices.py jobs.py config.py
web/      index.html  app.js  style.css  PedroDevLOGO.png
bin/      движки и модели — не в git
output/   готовые файлы
tmp/      тесты и промежуточные файлы задач
presets/  настройки и пресеты
run.bat              запуск
install-engines.ps1  скачивание движков
```

`server/main.py` отдаёт статику с `Cache-Control: no-store`, поэтому
закэшированный HTML не может объяснить поведение, которого нет на диске.

## Правка исходников

PowerShell 5.1 читает файл без BOM однобайтовой кодировкой и портит русский
текст, из-за чего код может молча перестать работать. Правьте файлы
инструментами, пишущими UTF-8; `install-engines.ps1` намеренно сохранён
с BOM — иначе PowerShell не разберёт русские строки в нём.
